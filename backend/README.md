# Backend API

Xem `../README.md` cho hướng dẫn tổng thể.

- Node + Express + MongoDB + JWT
- Trả JSON cho mọi endpoint
- CORS chỉ cho phép các origin trong `CORS_ORIGINS`
- Frontend (static) được host riêng (vd GitHub Pages), nói chuyện qua `fetch` với Bearer token

Chạy:
```bash
npm install
npm run dev
```
